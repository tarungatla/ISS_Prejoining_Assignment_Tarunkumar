# Python – ISS Pre-joining Assignment

This project contains Python practice programs created for the ISS pre-joining training. Each file or folder represents a specific topic with code examples and explanations.

---

## Topics Covered

| Topic No. | Topic Name          | Description                               |
|-----------|---------------------|-------------------------------------------|
| 1         | Variables            | Declaring and updating variables          |
| 2         | Constants            | Convention for defining fixed values      |
| 3         | Data Types & Structures | int, float, str, list, tuple, dict, set |
| 4         | Type Conversion      | Implicit and explicit conversions         |
| 5         | Control Flow         | if-else, loops, break, continue, pass     |
| 6         | Functions            | Defining and calling functions            |
| 7         | Error Handling       | try-except, else, finally, custom errors  |

---

## How to Run

1. Make sure Python is installed (recommended: Python 3.10+)
2. Open any `.py` file and run it using:
   ```bash
   python filename.py
